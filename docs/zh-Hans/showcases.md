# Showcases

MoUI 支撑多个原生和 Web 应用。下面列出带源码链接的重点 showcase。

## Mo Workbench

Mo Workbench 是以原生 Skia 为优先的桌面 agent dogfood 应用。它提供一个受
DeepSeek-GUI 启发的多工作区 shell，包含 Code chat、模型/思考控制、响应式布局
和 stub 后端。

GitHub 源码：https://github.com/wzzc-dev/MoUI/tree/main/examples/mo_workbench

## Markdown Editor

Markdown Editor 是一个 Typora 风格的 WYSIWYG 编辑原型，在源码和可视化编辑模式之间
共享一个带类型的 Markdown 应用模型。

GitHub 源码：https://github.com/wzzc-dev/MoUI/tree/main/examples/markdown_editor

## Showcase

Showcase 是 MoUI 的单一学习和诊断应用。它的共享应用被拆分为四个显式工作区：
Components 用于聚焦的可复用视图，Patterns 用于应用工作流，Platform 用于宿主服务
和移动探针，Diagnostics 用于运行时/渲染器检查。

GitHub 源码：https://github.com/wzzc-dev/MoUI/tree/main/examples/showcase

## Excel Viewer

Excel Viewer 使用 MoUI 数据表组件渲染 MoonBit Excel 文件。

GitHub 源码：https://github.com/wzzc-dev/MoUI/tree/main/examples/excel
