# MoUI 0.3.2

自 `0.3.0` 以来的工具链、语法与架构收口版本。25 个公开模块统一到
`0.3.2`，工具链基线升级到 MoonBit `0.10.20`，全 workspace 的升级 warning
清零，并纳入 ADR 0048–0058 的架构执行结果。

本版不引入应用面 API 破坏；但发布包的**最低 MoonBit 版本**变为
`0.10.20`。旧工具链不认识新的 `#derive(...)` 属性语法，继续使用
`0.10.16` 或更早版本的下游必须先升级。

## 工具链升级

| 项 | 版本 |
|---|---|
| `moon` | `0.1.20261104` |
| `moonc` | `v0.10.20+65efd5b93` |
| `moonrun` | `0.1.20261104` |
| `moonc-worker` | `0.1.202611052` |

`0.10.19+` 的迁移项已全部处理：

- trait derivation 从类型后的 `} derive(...)` 改为类型上方的
  `#derive(...)`。本仓库与 Studio 子仓合计迁移 **1,244 处**（workspace
  代码 `1,216`，Studio 代码 `27`，导出内核源码模板 `1`）；导出工程也通过
  新测试禁止旧后缀语法回流。
- `Json` / `ToJson` 的显式包路径已接入 `moonbitlang/core/json`。生成接口中
  的 `Json` 现在表现为 `@json.Json`，源码转换优先使用 `Json(value)`。
- boolean `inspect`、需要 `Show` 的断言和 `not(expr)` 已按新工具链改为
  `assert_true(...)` / `debug_inspect(...)` / `!expr`。
- `moon check` 现在会更新被检查本地包的 `pkg.generated.mbti`；本版提交了
  全量审阅后的接口变更。

`reb"..."` byte regex、top-level `declare let`、`Float::total_compare` 等
新能力已评估；当前没有能够同时改善 MoUI 热路径且降低风险的落点，因此本版
不为此制造无消费者的新用法。

## 架构执行结果（ADR 0048–0058）

- **渲染与更新缓存**：显式 `RenderCacheKey` 排除动画时钟；`ViewMemo` 提供
  caller-owned 的单子树内容键缓存；`ViewBuilderCache` 为 keyed 集合与条件
  槽位提供多条目构建缓存。
- **Damage 与滚动**：失效类别、paint damage 与 surface capability 分层；
  CPU raster 可以在显式 `SubRect` 下裁剪/清屏，并带像素自检。滚动布局改为
  content-local frame + `child_transform`，沿 paint、hit、focus、caret、
  semantics、anchor、overlay 与 platform-view 路径统一投影。
- **状态与输入**：`Feature::scope` 为 Effect/Subscription key 提供稳定命名
  空间；组件状态保持 Feature-first，不新增运行时 component store；指针手势
  arena 按 pointer id 仲裁 tap / long-press / drag。
- **扩展与诊断**：synchronized 0.3.x release line 记录为 ADR 0055；
  `DevtoolsTrace` 是 caller-owned、有界、只读 trace；ADR 0058 以证据否决
  `View::map` 的递归 copy 删除，保留类型安全的递归 adapter。

本版不包含 EGL partial presentation、payload 级事件日志、状态保留热重载或
运行时组件状态库；这些仍由各 ADR 的重开条件与后续 charter 管理。

## 兼容与迁移

只使用标准应用面的应用不需要改业务代码。升级步骤：

```sh
moon upgrade
moon update
moon fmt
moon check
```

如果下游代码自定义了派生类型，`moon fmt` 会把 `derive` 后缀迁移成
`#derive` 属性。若代码直接从旧的内建 `Json` 命名空间使用 `to_json()`，
请显式引入 `moonbitlang/core/json` 并改用 `Json(value)`。

`moui_cli` 生成工程与 Studio 导出工程的默认 MoUI family pin 均更新为
`0.3.2`。`moui_studio` companion 为 `0.1.5`。
