# Plan: Architecture-review follow-ups — renderer gates, dirty path, overlay closure, backend evidence

- **Status**: active
- **Goal**: Land the actionable findings of the 2026-09-05 architecture review as four independent workstreams: (A) renderer open-extension long-term gates, (B) runtime dirty-path/damage-region optimization with p50/p95 measurement and budget ratchets, (C) overlay closure including transition duration, reduced-motion, and the full macOS native modal presenter with matching-host smoke, (D) backend/common close-order evidence consolidation.
- **Non-goals**: no core API line budget mechanism (the review's "2128 budget" was a misread of the `docs/repository-facts.md` snapshot table — `validate-api-surface` passes at HEAD); no backend/common ports/state-machine redesign (the convergence plan already removed the three coordinators and gate-forbids their return); no new platform readiness claims from C4.

## Background

Verified against HEAD `0e95d491d` (2026-09-05):

1. `scripts/validate-renderer-provider-open-extension.mjs` exists, passes, and is wired into **no check profile** — it only runs when agents follow `docs/invariants.md`/`docs/testing.md` pointers. Its Check 2 factory matrix (`:123-135`) is a hardcoded closed set, so a new renderer silently gets zero coverage. `validate-backend-renderer-boundary.mjs:15` similarly closes the renderer-package regex.
2. `validate-options-field-drift.mjs` was promised by `docs/plans/done/renderer-backend-decoupling.md` (`:899-949`) and ADR 0007 (E7 throwaway-renderer gate) but never landed. Its original target layer (the 12 `<Platform><Renderer>AppOptions` forwarding structs) was deleted by `docs/plans/done/backend-renderer-extraction.md` (2026-08-04, "12 份转发层 → 0 份"), so the validator must be re-derived against the current options surface (`*HostAppOptions`/`*SmokeOptions`/`WebAppOptions` in `moui/backend/*`).
3. Runtime dirty path: `DirtyTracking` (`moui/runtime/runtime_state.mbt:469-486`) keeps 6 `Array[ElementId]` queues deduped by `push_unique_element_id` (`Array.any`, O(n²) per fold; `runtime_render_pipeline.mbt:349`), re-folded per phase by `refresh_dirty_element_queue` (`:520-537`). `compute_damage_region` (`:295-346`) does, per dirty id, `has_dirty_descendant` + `find_damage_bounds` on both previous and current trees — up to 4 full DFS traversals per id (worst case O(|dirty|²·n)); `has_dirty_descendant` itself is O(n·|dirty|) (`render_tree.mbt:287-296`). `mark_dirty` adds one O(n) element-tree DFS per marked id via `mark_paint_dirty_by_id` (`element.mbt:176-194`). `ElementId` does not derive `Hash`; repo idiom is `Map[K,V]` (no `HashSet` precedent).
4. Overlay: reduced-motion plumbing already exists end-to-end (`Environment.reduced_motion` → `RenderEnvironment.reduced_motion`, `render_environment.mbt:15`) but the two overlay fade sites ignore it — `RuntimeState::overlay_transition_duration_ms` hardcodes `160.0` (`runtime_render_pipeline.mbt:602-604`) and `overlay_enter_opacity` hardcodes `160.0` (`paint_engine.mbt:224`). `PresentationTransition` (`views/presentation/presentation.mbt:113-118`) carries no duration. Known open defect: deepseek settings-dialog Cancel-click assert (`examples/deepseek_harness_desktop/app/app_test.mbt:803`).
5. backend/common: `backend-renderer-lifecycle-convergence.md` completed the structural split (coordinators deleted, names forbidden by `checks/backend-common-ownership.json`); idempotency, stale/late completions, and cross-window rejection already have unit coverage. What is missing is one end-to-end sequence walk of the fixed close order (`docs/platform-host-contract.md:201-205`).
