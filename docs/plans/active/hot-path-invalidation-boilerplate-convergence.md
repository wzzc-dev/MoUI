# Plan: Hot-path, invalidation-semantics, and boilerplate convergence (2026-10 architecture analysis)

- **Status**: active
- **Goal**: Land the actionable findings of the 2026-10-31 architecture analysis as ten
  independent workstreams: (A) measurement baseline, (B) ambient theme landing per ADR 0036,
  (C) cache-invalidation convergence (generation semantics replacing structural Eq and
  whole-cache clears), (D) per-message sync throttling, (E) render-pipeline subtraction,
  (F) reconcile and event-path shortcuts, (G) Skia hot-key de-stringification,
  (H) declaration/derive codegen per ADR 0034 Option B, (I) platform-backend dedup,
  (J) intrinsic-sizing defaults (RFC-gated).
- **Non-goals**: `ViewNode` trait decomposition stays parked
  ([debt note](../debt/viewnode-trait-decomposition.md), MoonBit language limits);
  view-state slot storage stays parked pending profile evidence; renderer session
  closure style stays parked; no platform-readiness or renderer-route reclassification;
  no new renderer; no `backend/common` structural redesign beyond I's mechanical dedup;
  J lands only behind an API RFC.

## Background

Verified against HEAD `6c4d3bf0e` (2026-10-31) by three exploration tracks
(core/runtime, backend/render, views/examples) with key claims re-checked at HEAD.

The layering itself is healthy (dependency direction clean, `backend/common` free of
platform leakage, zero TODO/FIXME in `moui/`, debt/ADR culture present). The findings
cluster into four recurring root causes rather than structural flaws:

1. **Invalidation granularity — the shared architecture theme.** Five independent
   subsystems fail the same way ("invalidate by whole-cache clear, no dependency
   tracking"): measure/place cache keys compare the full `Environment` (embedding the
   complete `Theme`, 30+ color palette) structurally every element every pass
   (`moui/runtime/layout.mbt:40-43,100-104`); one image load completion clears the entire
   Skia layer cache (`moui_skia_renderer/renderer_image.mbt:589-594`); any overlay
   placement clears the whole place cache (`moui/runtime/runtime_render_pipeline.mbt:157-165`);
   the text paragraph cache full-clears on capacity with no LRU
   (`moui/core/text_paragraph_cache.mbt:182-208`); the renderer image lifecycle takes a
   full snapshot with O(records×pending) dedup per frame
   (`moui/render/renderer_session.mbt:300-321`).
2. **Per-message / per-frame constant overhead.** Every message (including scroll and
   pointer storms) rebuilds the whole `ActionCommandMap` with fresh closures and re-keys
   all subscriptions O(n²) (`moui/runtime/runtime.mbt:155-161`,
   `program_runtime_subscriptions.mbt:44,82-105`); `effect_plan_summary` walks the full
   effect tree per message for diagnostics only (`program_plan_summary.mbt:244`). Paint
   calls `text_context()` per node per frame, copying undo/redo arrays even for non-text
   nodes (`paint_engine.mbt:55,68` → `element_tree.mbt:110-111`). Reconcile has no
   declaration-equal subtree short-circuit and re-concatenates
   `"Modified<...>"` identity strings per diff (`element_reconcile.mbt:107-147`,
   `core/view_modifier_node.mbt:31-44`); `RuntimeViewAdapter.children()` rewraps every
   child per rebuild (`runtime/view_tree.mbt:87-89`).
3. **Render-pipeline DTO copies and dead code.** `RenderFrameMailbox` (222 lines) has zero
   production callers and overlaps `GpuRenderWorker`; the hybrid path copies command arrays
   the worker never consumes (`render/common/render_frame_mailbox.mbt`,
   `gpu_render_worker.mbt:171`, `moui_skia_renderer/hybrid_renderer.mbt:74-99`).
   `lower_draw_commands` mirrors all 27 `DrawCommand` variants into an equal-payload
   `PlanOp` array per frame, and scope-balance validation exists twice
   (`render/common/draw_plan.mbt:14-41,129-217` vs `capabilities_fallbacks.mbt:2-182`,
   whose sole production consumer scans the full stream per frame for one count —
   `moui_wgpu_renderer/native_renderer.mbt:746`).
4. **Boilerplate tax and example-taught anti-patterns.** Examples thread `theme~`
   1263 times; pinning `theme?` makes declarations `Uncacheable`
   (`views/common/declaration_helpers.mbt:48-52`), so every message reconciles as changed
   and clears the render cache — the examples teach users to disable paint caching
   (root cause of the ADR 0036 contrast incident). Controls lack intrinsic-size defaults
   (`views/text/text.mbt:14-25`), forcing pixel sizes everywhere and 8-11 optional
   constructor parameters. 57 of 63 ViewNodes hand-write declaration cache keys (ADR 0034
   Option B `generate_view_declarations` is the sanctioned generator, gated on its waiver
   baseline reaching zero); core carries 424 lines of `pub extend Debug/Eq/ToJson`样板
   (`core/paint.mbt`, `semantics.mbt`, `theme.mbt`). Desktop backends duplicate structurally
   (macos/linux/windows: 13/15 identical fields, identical forwarding and pump skeletons)
   and mobile backends repeat identical capability/binding four-pieces.

Relationship to existing records (do not contradict):

- Damage: renderer-side partial-damage infrastructure is complete; runtime damage
  computation is the declared next leverage point (4/5 benchmark scenarios return
  `FullSurface` from the runtime) — `memories/repo/skia-renderer-perf.md`.
- ADR 0035 mandates tight-fit child remeasure, so layout-pass reuse (B/C verification)
  must be conditional on the ADR 0035 refit not applying.
- ADR 0028's delivery sequence (renderer sessions own render resources and retained-layer
  residency) is accepted in its plan; the runtime flatten observation
  (`render_tree.mbt:137-152` cached commands re-flattened per frame) is measure-first and
  must reconcile with that ownership before any change.
