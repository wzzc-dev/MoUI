# 教案：班级小卖部 / Lesson: Class Store

- 建议学段：小学高年级 / 职校（财商 + 程序安全）
- 时长：1 课时
- 模板：顶栏「班级小卖部」

## 教学目标

1. 跨事件的状态：营业额不会因为换个按钮就归零（活状态跨事件累积）。
2. **安全闸门**：`提交数据` 会把程序停下来，等用户确认——这是可以讲给
   家长和学校听的安全叙事。
3. 表格控件：商品清单。

## 课堂步骤

1. **跑起来**（5 分钟）：点「卖一支铅笔」几次，营业额标签跟着涨。
2. **安全时刻**（10 分钟）：点「提交营业额」——程序**停下**，弹出
   「要把什么数据、送到哪里」，必须点「确认送出」才继续。讨论：
   为什么程序不能自己把数据发出去？（可对照：聊天软件发消息前的确认）
3. **读程序**（10 分钟）：卖铅笔（营业额加一 + 刷新标签）与记账
   （提交数据 + 信息框）。切到积木视图看聚光灯：运行时会高亮当前块。
4. **改一改**（10 分钟）：加一个「卖橡皮」（营业额 + 2），或在商品表
   里加两行货。
5. **讨论**（5 分钟）：执行记录里「闸门」那一条记下了确认/拒绝——
   日志有什么用？（复盘、追责、调试）

## 评价

- 能说出「确认之前没有任何数据离开程序」。
- 能独立加一个售价不同的商品按钮并跑通。

## 安全声明（给教师）

`提交数据` 在当前版本是**闸门化模拟动作**：它只写入执行记录并等待人工
确认，不发起任何真实网络请求。真实外发能力不在 v1 范围内。
