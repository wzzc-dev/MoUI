# MoUI 0.7.2 — Observable, steerable Skia downloads

Patch release since `0.7.1`. All 26 public modules move to `0.7.2` together on
the existing `0.7.x` line (ADR 0065; the line does not advance), which carries
bug fixes and documentation only. The prebuild Skia fetch helpers become
observable and steerable — live progress, mirror listing and choice, default
speed probe — with no public API, package boundary, or wire-contract change.

## Download progress and mirror control

- **Progress**: `MOUI_SKIA_PROGRESS=auto|off|stderr|tty` (`--progress MODE`,
  `--no-progress`) reports bytes and throughput. `auto` writes to `/dev/tty`
  (`CONOUT$` on Windows) because `moon` captures a prebuild's stderr; it falls
  back to stderr without a terminal and never uses stdout.
- **Mirrors**: `--list-mirrors` (`-ListMirrors`) prints recorded sources and
  downloads nothing; `--mirror NAME` / `--no-mirror` (`-Mirror` / `-NoMirror`)
  and `MOUI_SKIA_MIRROR` order or isolate candidates.
- **Default probe**: in `auto` mirror mode, before a release asset of at least
  4 MiB, `MOUI_SKIA_PROBE=auto` times each candidate's first 256 KiB once per
  invocation and starts from the fastest. It only reorders; every download
  still verifies the locked SHA256 and size. `--no-probe` / `-NoProbe` /
  `MOUI_SKIA_PROBE=off` disables it, explicit mirror modes skip it, and
  inspection modes are rejected with `--print-env` so stdout stays readable.
- Bash/PowerShell parity; the offline 31-check suite runs in `pr-static` on a >4 MiB fixture.

## Verification

- Range `0.7.1 → 0.7.2`: 7a8ef0d8 (downloader) and 2f08612d (docs). `dev` run
  44906388840 on 2f08612d is green; platform jobs were skipped by change scope.
- Local gates: static validator set and offline mirror suite. Registry: all 26
  modules at `0.7.2`, each returning `Server status: 200 OK`.

## Upgrade notes

- Update dependencies; no public symbol, package boundary, or wire contract
  changed. The `wzzc-dev/window` pin stays at `0.5.4-0.2.13`.
- A fresh cache pays the probe (seconds); `MOUI_SKIA_PROBE=off` skips it. `--print-env`
  and `moui_skia/build.mbtx` are unchanged.

# MoUI 0.7.2 —— 可见、可控的 Skia 下载

自 `0.7.1` 以来的补丁版本。26 个公开模块统一到 `0.7.2`，仍在 `0.7.x`
发布线（ADR 0065，不推进线号），只含修复与文档。预构建的 Skia fetch 工具
变得可观察、可控制：实时进度、源列表与选择、默认测速；公开 API、包边界、
宿主协议均未变。

## 进度与源控制

- **进度**：`MOUI_SKIA_PROGRESS=auto|off|stderr|tty`（`--progress MODE`、
  `--no-progress`）报告字节与速度。`auto` 写 `/dev/tty`（Windows 为
  `CONOUT$`），因为 `moon` 会吞掉 prebuild 的 stderr；无终端时回退 stderr，
  且永不写 stdout。
- **源**：`--list-mirrors`（`-ListMirrors`）只列出记录在案的源、不下载；
  `--mirror NAME` / `--no-mirror`（`-Mirror` / `-NoMirror`）与
  `MOUI_SKIA_MIRROR` 可指定或排除候选。
- **默认测速**：`auto` 源模式下，≥4 MiB 的 release 资产下载前，
  `MOUI_SKIA_PROBE=auto` 为每个候选测 256 KiB、每次调用只测一轮，并从最快
  源开始；只调整顺序，每次下载仍校验锁定的 SHA256 与大小。
  `--no-probe` / `-NoProbe` / `MOUI_SKIA_PROBE=off` 可关闭；显式指定源时
  自动跳过；巡检模式与 `--print-env` 互斥，stdout 保持机器可读。
- Bash 与 PowerShell 同构；`pr-static` 的离线 31 项套件用 >4 MiB fixture 覆盖测速。

## 验证

- `0.7.1 → 0.7.2` 范围：7a8ef0d8（下载器）与 2f08612d（文档）。`dev` 上
  run 44906388840（`2f08612d`）为绿；平台 job 按变更范围 skipped。
- 本地门禁：静态校验套件与离线镜像测试。注册表：26 个模块均为 `0.7.2`，
  每条返回 `Server status: 200 OK`。

## 升级说明

- 更新依赖即可；公开符号、包边界与协议均未变。`wzzc-dev/window` 的 pin
  仍是 `0.5.4-0.2.13`。
- 全新缓存先付测速的几秒；CI 可用 `MOUI_SKIA_PROBE=off`，`--print-env` 与 `build.mbtx` 未变。
