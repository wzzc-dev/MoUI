# Plan: MoUI Studio 工程工作台——代码真源 + 三模式预览 + 拖拽设计器

- **Status**: active
- **Goal**: 把 MoUI Studio 从「`.studio.json` 单程序 IDE」升级为「MoUI 工程工作台」:**逻辑真源 = MoonBit 文件**(尽快全面切换,教学功能立即重定向,`.studio.json` 退役),三视图(设计/积木/中英代码)成为真源之上的外观;三模式预览(画布内快览 / web+webview 实时 / native 真跑)直接消费任意 counter 式 MoonBit 工程;左栏资源管理器管理工程与文件;积木随 IR 生长长成「Blockly for MoonBit」。
- **Non-goals**: 自由 2D 多脚本画布与 minimap(与单 handler 聚焦定位冲突);通用 MoonBit 语言服务器;移动端;真实网络外发(沿用 v1 冻结);TEA 形态工程(counter 原样)的逻辑积木化——除非 IR 生长覆盖。

## 背景与决策(2026-10-04 会话收敛)

1. **真源决策(用户已定)**:尽快全面切换——逻辑真源直接是 MoonBit 文件(`handlers.mbt` + `form.mbt`),不引入 script(DSL)持久层与 `.studio.json` 覆盖层;模板/AI 提案立即重定向,接受教学功能短窗期重构;`.studio.json` 提供一次性迁移器后删除读路径(跨代拒绝纪律)。
2. **IR 的新角色**:从持久化格式退居**内存语义模型**——parse 产物、编辑枢纽、永不落盘。积木手术层(`domain/blocks` 路径手术/表达式槽/快照)、解释轨(单步/审计/聚光灯)、双轨差分门、AI 提案校验链全部以 IR 为类型。升级:节点带**源码 span**(补丁式回写,文本保真)。
3. **积木覆盖的诚实边界**:积木 = 「IR 同构 MoonBit 子集」的编辑器;子集 = `moonbit_codegen` 生成形状(封闭、可测);子集外函数只读标注。扩大覆盖 = IR 逐构造生长(每构造九面:parser/printer/interp/codegen/compiled_runtime/blocks/codec|signature + 双轨差分门)。
4. **执行顺序(用户已定)**:依赖顺序 M0→M8,每期退役下一期最大的不确定性。
