# MoUI 0.9.0 — Navigation surface

Minor release since `0.8.0`: all 26 public modules move to `0.9.0` on the `0.9.x`
line. Additions only: nothing is removed or renamed, every new parameter is
defaulted, no enum gains a variant. The `SemanticsRole` variants, `inline_edit`,
and general drag and drop move to a later patch on this line.

## Tree and tabs

- `tree_view` gains `active~`, `on_activate~`, `on_secondary_tap_with_frame~`,
  `hovered~`, `on_hover~`, and `indent_guides~`; the active row takes a 1 pt
  `primary` border, hovered rows `surface_variant`, and guides add 6 + 1 + 9 pt
  per level.
- `tree_visible_ids` flattens the tree into visible rows, and
  `tree_navigation_target` maps a `KeyboardEvent` to a
  `TreeNavigationTarget { id, effect }` (`Focus` / `Expand` / `Collapse` /
  `Activate`): Down/Up stop at the ends, Home/End jump, Enter/Space activate,
  Left/Right collapse and expand.
- `tab_item` gains `closable? = false`, `dirty? = false`, `icon? = None`, and
  `pinned? = false`; a chip shows at most one trailing marker, and only when
  closable with `on_close`.
- `tab_strip` is new: selected chips use `palette.surface` on a 6 pt radius, a
  `tab-<route>` key, and `Tab` semantics; a weighted spacer pushes `trailing~` to
  the end. `tab_view` keeps its signature.

## Command menu

- `command_menu` gains `active? : Int32 = -1` and `on_hover?`; the active row
  uses `primary_container` with a 1 pt `primary` border.
- `command_menu_navigation_index` covers Down/Up/Home/End with `wrap?`, and
  `command_menu_type_ahead_match` matches one character as a lowercase prefix
  after the active row, wrapping around.

## Chrome

- `focus_ring` gains `focus_visible? = true`: 2 pt `primary` when lit, a 1 pt
  zero-alpha slot when focused but hidden, `outline` at `0.42` otherwise.
- `markdown_find_bar` gains `compact? = false`, dropping the inline
  "Find"/"Replace" labels (fields `196 → 104`, status `88 → 44`), so a 760 pt
  slot fits where the full bar overflows.
- `View::on_context_menu_key(handler)` dispatches once for the ContextMenu/Menu
  key or Shift+F10, anchored at the frame's bottom-left.

## Verification

- Range `0.8.0 → 0.9.0`: 46c79b33 (merge of #31) plus the version commit.
- `MoUI pr checks passed.`; API surface, maintenance baseline, generated
  interfaces, release module closures, doc budget, and doc references green;
  package tests 6/6, 18/18, 53/53, and 51/51.
- All 26 modules published at `0.9.0` (HTTP 200 each, manifests unyanked).

## Upgrade notes

- Update dependencies; nothing existing changes. `TreeNavigationTarget` is a new
  `pub(all)` struct, so `moui/views` gains one public type.
- MoSpace can drive tree keyboard navigation, give the tab overflow button a slot
  through `tab_strip`, and use `markdown_find_bar` in `compact~` mode.
- `tab_item` has no `tooltip~` and `tab_strip` no `on_reorder~` yet; both wait for
  a later release.

# MoUI 0.9.0 —— 导航面

自 `0.8.0` 以来的次版本：26 个公开模块统一到 `0.9.0`，进入 `0.9.x` 发布线。
改动只做加法：不删除、不改名既有公开符号，新增参数一律带默认值，也没有枚举新增
variant。`SemanticsRole` 的三个 variant、`inline_edit` 与通用拖放留到这条线的后续补丁。

## 树与标签

- `tree_view` 新增 `active~`、`on_activate~`、`on_secondary_tap_with_frame~`、
  `hovered~`、`on_hover~`、`indent_guides~`；活动行描 1 pt `primary` 边框，
  悬停行用 `surface_variant`，缩进引导每级 6 + 1 + 9 pt。
- `tree_visible_ids` 摊平成可见行；`tree_navigation_target` 把 `KeyboardEvent`
  映射为 `TreeNavigationTarget { id, effect }`（`Focus` / `Expand` /
  `Collapse` / `Activate`）：上下键到端点即停，Home/End 跳首尾，Enter/空格
  激活，左右键折叠展开。
- `tab_item` 新增 `closable? = false`、`dirty? = false`、`icon? = None`、
  `pinned? = false`；chip 最多一个尾随标记，且需可关闭并给了 `on_close`。
- `tab_strip` 为新函数：选中 chip 用 `palette.surface`、圆角 6，键为
  `tab-<route>`，语义 `Tab`；权重 spacer 把 `trailing~` 顶到末端。`tab_view`
  签名不变。

## 命令菜单

- `command_menu` 新增 `active? : Int32 = -1` 与 `on_hover?`；活动行用
  `primary_container` 加 1 pt `primary` 边框。
- `command_menu_navigation_index` 处理上下/Home/End 并支持 `wrap?`；
  `command_menu_type_ahead_match` 取单字符小写前缀，从活动行之后回绕查找。

## 外壳细节

- `focus_ring` 新增 `focus_visible? = true`：亮环 2 pt `primary`，聚焦但隐藏时
  保留 1 pt 零透明度槽位，其余 `outline` 取 `0.42`。
- `markdown_find_bar` 新增 `compact? = false`，去掉行内 "Find"/"Replace"
  文案（字段 `196 → 104`、状态 `88 → 44`），760 pt 槽位即可容纳。
- `View::on_context_menu_key(handler)` 对 ContextMenu/Menu 键或 Shift+F10
  派发一次，锚点取 frame 左下角。

## 验证

- 区间 `0.8.0 → 0.9.0`：46c79b33（#31 合并）及版本提交。
- `MoUI pr checks passed.`；API surface、维护基线、生成接口、发布模块闭包、
  文档预算与文档引用全绿；包内测试 6/6、18/18、53/53、51/51。
- 26 个模块均已发布 `0.9.0`（逐个 HTTP 200，manifest 未撤回）。

## 升级说明

- 更新依赖即可，既有内容未变；`TreeNavigationTarget` 是新 `pub(all)` 结构体，
  `moui/views` 因此多一个公开类型。
- MoSpace 可接树上键盘导航、用 `tab_strip` 给溢出按钮留位、把
  `markdown_find_bar` 换成 `compact~`。
- `tab_item` 还没有 `tooltip~`、`tab_strip` 还没有 `on_reorder~`，等后续版本。
