# MoUI 0.10.2 — Interrupt command intent

Patch note on the `0.10.x` line. `0.10.1` was published before the Interrupt
change landed, and those registry artifacts remain unchanged; this release uses
`0.10.2`. `CommandIntent::Interrupt` is a new public enum variant: exhaustive
downstream matches need one more arm, so this is source-level breaking under
the pre-1.0 allowance. Release prep publishes `0.10.2` across the synchronized
modules with this upgrade note.

- Plain Ctrl+C (no Shift/Meta/Alt) maps to `Interrupt`; Cmd+C stays `Copy`;
  Ctrl+Shift+C and Ctrl+Insert are copy chords; cut/paste are unchanged.
- Focused text controls ignore `Interrupt` instead of consuming it as `Copy`,
  so the `ActionCommand`/`ProgramCommand` table receives it. MoUI ships no
  default `Interrupt` command or shortcut; apps own terminal/cancel behavior.
- Upgrade: add an `Interrupt` arm to exhaustive matches. A terminal that handled
  Ctrl+C as raw keyboard input binds `Interrupt` to writing `\x03`; copy uses
  Cmd+C, Ctrl+Shift+C, or Ctrl+Insert. Depend on `0.10.2` or later.

`CommandIntent::Interrupt` 是公开枚举的新 variant，下游 exhaustive match
必须补分支；按 pre-1.0 规则，这是带升级说明的源码级破坏性变更。普通 Ctrl+C
映射为 `Interrupt`，Cmd+C / Ctrl+Shift+C / Ctrl+Insert 仍为复制，剪切/粘贴不变；
聚焦文本框不消费 `Interrupt`，交给应用的 ActionCommand/ProgramCommand。MoUI
不提供默认 `Interrupt` 命令或快捷键。`0.10.1` 在 Interrupt 落地前已发布且制品
保持不变，本次发布同步推进到 `0.10.2`。
