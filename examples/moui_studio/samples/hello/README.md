# 教案：问候 / Lesson: Hello App

- 建议学段：小学高年级 / 零基础第一课（信息科技）
- 时长：0.5–1 课时
- 模板：顶栏「问候小程序」

## 教学目标

1. 认识三视图：同一个程序，设计视图管"长什么样"，积木视图管"做什么"，
   代码视图管"怎么写出来"——它们是同一个程序。
2. 完成第一次"改程序 → 运行 → 看结果"的完整闭环。
3. 第一次观察执行记录（审计时间线）：程序每一步都留下了"人话"痕迹。

## 课堂步骤

1. **跑起来**（5 分钟）：直接点「运行」。点按钮，看标签从"你好！"
   变成"你好，MoUI Studio！"。问：谁改了标签？（设置文本 这条命令。）
2. **找到那句话**（8 分钟）：切到积木视图——只有一条命令积木；
   再切到代码视图——只有一行 `设置文本(显示, "你好，MoUI Studio！")`。
   三个视图说的是同一件事。
3. **改一改**（10 分钟）：把 `"你好，MoUI Studio！"` 改成学生自己的名字
   （代码视图直接改 / 积木视图点选那条积木在编辑器里改），点运行再看。
   再到设计视图把按钮文字改掉——注意代码里的文本没有变，变的是
   按钮的"文本"属性（属性面板）。
4. **撤销体验**（5 分钟）：故意改乱 → 顶栏「撤销」逐步退回。
   问：撤销了多少步？每一步改了什么？
5. **毕业预览**（5 分钟）：切到「MoonBit」页——这段程序"翻译"成
   真代码大概长什么样。告诉学生：学完可以一直走到写真正的代码。

## 可提问的拓展

- 标签和按钮有什么不一样？（一个只显示，一个能点。）
- 如果想点按钮时改两个标签，程序里要几条 设置文本？
- 执行记录里每一步的颜色代表什么？（赋值蓝 / 信息框绿 / 闸门朱砂。）
