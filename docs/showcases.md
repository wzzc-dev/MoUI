# Showcases

MoUI powers several native and Web applications. Below are the featured
showcases with source links.

## Mo Workbench

Mo Workbench is the native-Skia-first desktop agent dogfood app. It provides a
multi-workspace shell inspired by DeepSeek-GUI with Code chat, model/thinking
controls, responsive layout, and stub backend.

GitHub source: https://github.com/wzzc-dev/MoUI/tree/main/examples/mo_workbench

## Markdown Editor

Markdown Editor is a Typora-style WYSIWYG editing prototype that shares one
typed Markdown application model between source and visual editing modes.

GitHub source: https://github.com/wzzc-dev/MoUI/tree/main/examples/markdown_editor

## Showcase

Showcase is the MoUI visual component catalog. It covers layout, input,
rendering, and platform smoke paths through a single shared app package.

GitHub source: https://github.com/wzzc-dev/MoUI/tree/main/examples/showcase

## Excel Viewer

Excel Viewer renders MoonBit Excel files with MoUI data table components.

GitHub source: https://github.com/wzzc-dev/MoUI/tree/main/examples/excel

## MoUI Quick Example

A minimal counter app that demonstrates the core MoUI patterns in the smallest
possible surface: Model, Msg, update, view, and Program::simple. This is a
standalone repository at `moui-mbt/moui_example`.

GitHub source: https://github.com/moui-mbt/moui_example
