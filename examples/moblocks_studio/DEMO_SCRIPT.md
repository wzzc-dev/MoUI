# MoBlocks Studio 演示视频脚本

两个版本：**3–5 分钟主版本**（评审播放）与 **8–10 分钟完整版**（备用/深挖）。
全程使用**假模型（确定性，离线）**——录制不需要联网，评审现场也不依赖网络。

## 8–10 分钟完整版（备用）

在主版本骨架上增加：

1. **范式讲解**（+1 min）：积木目录表、端口类型系统、BlockGraphProposal v2 schema。
2. **校验器深挖**（+1.5 min）：现场构造三种坏图——缺确认的外发图、类型错连、环——分别给出中文拒绝原因。
3. **撤销/重做与历史**（+30 s）：施加若干编辑后 25 步撤销回到基线。
4. **执行器语义**（+1.5 min）：Timeout 超时转失败、Retry 三次重试后失败、下游级联跳过、取消保留已完成记录。
5. **审计导出**（+30 s）：Markdown 审计报告的内容走读。
6. **项目 codec**（+30 s）：.moblocks.json v1 往返字节一致、未知格式拒绝。
7. **真实 provider**（+1 min，仅桌面）：切到真实模式 → endpoint/key → 生成同 schema 图。
8. **MCP 边界**（+30 s，如评委问起）：比赛版刻意不做 MCP 集成——`moui_agent`/`moui_agent_mcp` 保持「外部 Agent 操作 MoUI」的定位，产品域的 MCP client 是赛后路线图第一项。
9. **测试与质量**（+1 min）：native + wasm-gc 双端测试、六个仓库静态校验；可讲框架侧澄清——一度怀疑 row 命中/`on_drag` 缺陷，复核后确认是画布局部坐标与屏幕坐标混用导致的测试误判，并补了 `moui/runtime` 指针输入回归（`done/row-child-hit-testing.md`）。

## 录制注意事项

- 用假模型，固定帧录制；窗口 1280×800。
- 录 Web 路径时必须从仓库根起静态服务器（`python3 -m http.server`），避免相对路径 404。
- 画布积木拖拽可用（按下选中、拖动移动）；若想稳妥，节点选择也可走底部「选择积木」按钮列表。
