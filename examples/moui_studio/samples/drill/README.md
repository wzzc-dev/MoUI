# 教案：口算训练营 / Lesson: Arithmetic Drill

- 建议学段：小学 2–4 年级（数学 + 信息科技跨学科）
- 时长：1–2 课时
- 模板：顶栏「口算训练营」

## 教学目标

1. 理解「变量保存中间结果」：题目里的两个数出题时记下来，批改时再用。
2. 读懂分支：`如果 … 则 … 否则 … 结束`。
3. 体验运行记录：每一步程序做了什么，都写在「执行记录」里。

## 课堂步骤

1. **跑起来**（5 分钟）：点「出一新题」→ 在输入框写答案 → 点「批改」，
   看判定标签。故意答错一次，看记录里分支走了哪边。
2. **读程序**（12 分钟）：两个子程序——出题（随机两个数、拼题目、
   清空答案框）与批改（比较答案与两数之和）。切到积木视图看同样
   两段逻辑长什么样。
3. **改一改**（10 分钟）：把 `随机数(20)` 改成 `随机数(100)`，题目
   变难；试着改判定文案（`答对了！`）。
4. **挑战**（10 分钟）：加一个「连对 3 题表扬一次」。提示：需要一个
   记录连对次数的变量（程序变量面板/`变量` 声明）。
5. **思辨**（3 分钟）：出题是随机的，怎么保证每次跑出来的题可复现？
   （可播种随机数——测试靠它。）

## 评价

- 能指出「第一个数/第二个数」变量为什么必须在出题时保存。
- 能独立把上界从 20 改到 50 并跑通。
