# MoUI 0.7.x — release line index

`0.7.0` advanced the synchronized line from `0.6.x` to `0.7.x` (ADR 0065);
`0.7.1`–`0.7.3` were patches on that line. All 26 public modules moved
together in every release. This page keeps the themes and the upgrade notes;
the full per-release record (verification runs, measurement tables, PR detail)
stays in the git history at the corresponding tag.

| Release | Theme | Public API |
| --- | --- | --- |
| `0.7.0` | Linux frame clock, Sun ↔ Skia parity, window chrome | additive |
| `0.7.1` | Sun Linux font candidates | none |
| `0.7.2` | Observable, steerable Skia downloads | none |
| `0.7.3` | Same-window native dev reload (macOS) | none |

## 0.7.0 — Linux frame clock, Sun parity, window chrome

- Linux installs a real `CLOCK_MONOTONIC` frame clock (`linux_frame_clock`),
  so motion durations are wall-clock instead of a fixed 16 ms step; opt out
  with `LinuxHostAppOptions::new(frame_clock=None)`.
- Sun ↔ Skia parity: platform font discovery on Linux (Fontconfig faces),
  macOS (CSS weight) and Windows (system enumeration), CJK and symbol
  fallback, shared ascent spans, and Skia-aligned text origin/shader space.
  Raster hot paths use analytic row coverage; macOS presents through
  IOSurface.
- Window chrome: view-declared cursors (`CursorStyle`/`CursorIcon`,
  `View::cursor`), new `WindowRequest` variants and surface actions, and
  `WindowControlSource` chrome insets (`wzzc-dev/window` → `0.5.4-0.2.13`).
- p5 canvas path-clip, stroke and blend-mode surface; `moonc 0.10.22` pin
  with `build.mbtx` prebuild hooks and published Skia stub assets.
- `moui package` finds `cmd/<platform>` entrypoints and falls back to
  `moon.mod` for the build root.

Upgrade notes:

- Update dependencies. No public symbol was removed; the release line,
  workspace pins and closure checks move to `0.7.x` together.
- New APIs are additive, so existing apps compile unchanged; a view without a
  cursor declaration keeps the platform default. Update the `window` pin with
  MoUI.
- A `moon.work` workaround for packaging is no longer needed. Existing
  bundles keep working, but should be regenerated for the corrected
  `.desktop` `Exec`/`TryExec` entry.

## 0.7.1 — Sun Linux font candidates

Patch since `0.7.0`, bug fixes only. Sun picked the fontconfig generic role
(`sans-serif`) while Skia walks an explicit candidate list, so on a Noto-based
host the two renderers drew different faces. Sun now probes the same
candidates in the same order (`renderer_platform_font_query.c`), accepts a
candidate only when `fc-match` echoes the requested family, and still falls
back to the generic role when nothing matches.

Upgrade notes:

- Update dependencies; nothing public was added or removed, and the `window`
  pin is unchanged.
- On a Linux host where the generic `sans-serif` resolves to a family that is
  not first in the Skia candidate list, Sun now draws the family Skia draws.
  Text metrics on those hosts change slightly — that is the fix.
- Apps that bundle and register their own faces are unaffected.

## 0.7.2 — Observable, steerable Skia downloads

Patch since `0.7.1`, bug fixes only. The Skia asset probe and download now
report progress and honour a mirror, so a slow or blocked source is visible
instead of appearing as a hang.

Upgrade notes:

- Update dependencies; nothing public changed, and the `window` pin stays at
  `0.5.4-0.2.13`.
- A fresh cache pays the probe (seconds); `MOUI_SKIA_PROBE=off` skips it.
  `--print-env` and `moui_skia/build.mbtx` are unchanged.

## 0.7.3 — Same-window native dev reload

Patch since `0.7.2`, developer tooling only. On macOS the dev host reloads the
app inside the same window with `--hot`, instead of restarting it and losing
window state.

Upgrade notes:

- Update dependencies; nothing public changed, and the `window` pin stays
  `0.5.4-0.2.13`.
- `--hot` is macOS-only and dev-only; the target app module must be listed in
  `moui_devhost/moon.mod`. Other platforms keep restart + state.

# MoUI 0.7.x —— 发布线索引

`0.7.0` 把同步线从 `0.6.x` 推到 `0.7.x`（ADR 0065），`0.7.1`–`0.7.3` 是这条
线上的补丁版本。26 个公开模块每次都一起推进。本页保留各版主题与升级说明；
逐版完整记录（验证 run、度量表、PR 细节）留在对应 tag 的 git 历史里。

## 0.7.0 —— Linux 帧时钟、Sun 追平、窗口 chrome

- Linux 装上真正的 `CLOCK_MONOTONIC` 帧时钟（`linux_frame_clock`），动画时长
  按墙钟算，不再是每帧固定 16 ms；可用
  `LinuxHostAppOptions::new(frame_clock=None)` 关掉。
- Sun ↔ Skia 追平：Linux 走 Fontconfig face、macOS 按 CSS weight、Windows
  枚举系统字体；补齐 CJK 与符号回退、混合脚本共享 ascent、与 Skia 对齐的
  文本原点和着色器空间。光栅热路径改为解析式按行覆盖；macOS 经 IOSurface 呈现。
- 窗口 chrome：视图声明 cursor（`CursorStyle`/`CursorIcon`、`View::cursor`）、
  新的 `WindowRequest` 变体与 surface action、`WindowControlSource` 的 chrome
  内边距（`wzzc-dev/window` → `0.5.4-0.2.13`）。
- p5 canvas 的 path-clip、stroke 与 blend-mode；`moonc 0.10.22` pin，加上
  `build.mbtx` 预构建钩子和已发布的 Skia stub 资源。
- `moui package` 能找到 `cmd/<platform>` 入口，并以 `moon.mod` 作为构建根兜底。

升级说明：

- 更新依赖即可；没有删除公开符号。发布线、workspace pin 与 closure 检查
  一起移到 `0.7.x`。
- 新增 API 都是加法，既有 app 无需改动；没有声明 cursor 的视图保持平台默认。
  `window` 的 pin 要跟 MoUI 一起更新。
- 打包不再需要 `moon.work` 变通；既有 bundle 仍可用，但建议重新生成以拿到
  修正后的 `.desktop` `Exec`/`TryExec`。

## 0.7.1 —— Sun 的 Linux 字体候选表

自 `0.7.0` 的补丁，只修 bug。Sun 问的是 fontconfig 通用角色（`sans-serif`），
Skia 走显式候选表，装了 Noto 的宿主上两者画出的 face 不同。现在 Sun 按同样
顺序探测同样候选表（`renderer_platform_font_query.c`），只有 `fc-match` 回显
请求 family 才接受，全部未命中时仍回退通用角色。

升级说明：

- 更新依赖即可；没有新增或删除公开符号，`window` pin 与 `0.7.0` 相同。
- 在通用 `sans-serif` 解析到「不在 Skia 候选表首位」的 Linux 宿主上，Sun 现在
  画 Skia 画的那个 family；这些宿主的文本度量会有轻微变化，这是修复本身。
- 自带并注册 face 的 app 不受影响。

## 0.7.2 —— 可见、可控的 Skia 下载

自 `0.7.1` 的补丁，只修 bug。Skia 资源探测与下载现在报告进度并支持镜像，
慢源或被墙的源不再表现为「卡住」。

升级说明：

- 更新依赖即可；公开面未变，`window` pin 仍是 `0.5.4-0.2.13`。
- 空缓存要付一次探测（秒级）；`MOUI_SKIA_PROBE=off` 可跳过。
  `--print-env` 与 `moui_skia/build.mbtx` 不变。

## 0.7.3 —— 同窗口原生开发重载

自 `0.7.2` 的补丁，只动开发工具。macOS 上 dev host 用 `--hot` 在同一窗口内
重载 app，不再重启并丢掉窗口状态。

升级说明：

- 更新依赖即可；公开面未变，`window` pin 仍是 `0.5.4-0.2.13`。
- `--hot` 只在 macOS 的开发态可用；目标 app 模块要列进
  `moui_devhost/moon.mod`。其他平台保持重启 + 状态恢复。
