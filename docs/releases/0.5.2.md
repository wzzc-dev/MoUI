# MoUI 0.5.2

`0.5.x` 同步行内的补丁版。25 个公开模块统一到 `0.5.2`，无依赖侧 pin 变化。

修复：web 渲染器（WebGPU 主线与 Canvas2D 降级共用的 WebGPU 适配层）的
`push_layer` 现在把层 mask 从节点局部坐标变换到屏幕空间（与 `push_clip`
一致）。此前嵌套视图内的保留层会被屏幕空间 clip 裁成空——网站
Playground 的代码编辑器因此只画得出界面框而画不出代码文本。根级视图
不受影响（局部坐标恰等于屏幕坐标），所以该回归只出现在嵌套层场景。
该修复同时清理了 `runtime.js` 里被合并误嵌入 `push_layer` 字面量中间的
`three_d_update_resources`。

无应用面 API 变更。从 `0.5.1` 升级只需更新依赖。
