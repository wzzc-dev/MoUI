# MoUI 0.8.0 — Shared Markdown input surface

Minor release since `0.7.3`: all 26 public modules move to `0.8.0` on the new
`0.8.x` line (ADR 0065), and the WYSIWYG Markdown input path MoMark and MoSpace
each reimplemented is now published, so both apps drop their copies. Additions
only: no existing public symbol or wire contract change, every new knob defaulted.

## Editor model

- `MarkdownDocumentSession::target_at(selection)` returns a `MarkdownEditorTarget`
  (`kind`, `block_kind`, `block_label`, link/image/footnote/html payloads);
  `has_openable_target` gates menu commands. Precedence: `HtmlBlockTarget` >
  `FootnoteTarget` > `LinkTarget` > `ImageTarget` > `TableTools` >
  `PlainSelection` — footnotes first, since `[^1]` is legal reference syntax.
- `MarkdownEditHistory` records via `record` (clock via `at_ms~`; same-kind
  single-character edits merge within 500 ms), replays via `undo` / `redo`, and
  exposes `can_undo` / `can_redo` / `clear`. `selection_before~` /
  `selection_after~` let undo and redo return a `MarkdownEditOutcome` with the
  recorded selection; `None` falls back to the caret, a diverged source to `None`.

## Wiki links, opt-in

- `MarkdownWikiLinkOptions::new(scheme)` plus `with_wiki_links` enable
  `[[target]]` / `[[target|label]]`; default off, no built-in scheme, so the app
  injects its own.
- Inlines keep the raw target for lossless round-trips and resolve only at click
  time. `MarkdownInline` gains `wiki : Bool = false`, which — not a URL prefix —
  drives write-back, so a normal link whose target is `wiki:foo` is untouched.

## Reader and editor chrome

- `markdown_viewer` gains `palette~` (joins the document cache key),
  `compact_blank_gaps~` (folds inactive gaps for hit testing and painting, not
  only layout), and `wiki_links~`.
- Styled tables get the visible-run source shift with grapheme cluster advance, a
  per-cell paint clip, and `line_index~` on the caret-hit helper.
- `moui_markdown` adds `markdown_editor_surface_menu_items` (`action` is the
  existing command word, so one string maps to one `Msg`) and the format bubble
  with action list, glyph, label, and rect helpers; it flips below the caret and
  clamps y, never x.

## Verification

- Range `0.7.3 → 0.8.0`: 24b2f880, daa109e9, 7d3e2862 (merge of #30), plus the
  version commit. PR gate on 7d3e2862: 1418/1418 (wasm), 51/51 (wasm-gc),
  2770/2770 (native); local `moui_richtext` 387/387 and `moui_markdown` 48/48,
  with static validators, generated interfaces, and the doc budget green. All 26
  modules are published at `0.8.0` (HTTP 200 each, manifests unyanked).

## Upgrade notes

- Update dependencies; no existing symbol or wire change. `MarkdownInline` gained
  `wiki : Bool = false`, so its `to_json` gains a key.
- MoMark drops `editor_target_sync.mbt`, its undo grouping, context-menu tables,
  and `view_format_bubble.mbt` for the APIs above. MoSpace drops
  `vendor/moui_richtext` for `palette~`,
  `wiki_links~ = Some(MarkdownWikiLinkOptions::new("mospace-wiki:"))`, and
  `compact_blank_gaps~ = true`; compact gaps stay off by default.

# MoUI 0.8.0 —— 共享 Markdown 输入面

自 `0.7.3` 以来的次版本：26 个公开模块统一到 `0.8.0`，进入新的 `0.8.x` 发布线
（ADR 0065），MoMark 与 MoSpace 各自重写的所见即所得 Markdown 输入面改为发布包，
两个应用因此删掉自己的副本。改动只做加法：既有公开符号、包边界与线协议不变，
新增参数一律带默认值。

## 编辑模型

- `MarkdownDocumentSession::target_at(selection)` 返回 `MarkdownEditorTarget`
  （`kind`、`block_kind`、`block_label` 与链接/图片/脚注/HTML 载荷），
  `has_openable_target` 供菜单判断命令是否可用。优先级：`HtmlBlockTarget` >
  `FootnoteTarget` > `LinkTarget` > `ImageTarget` > `TableTools` >
  `PlainSelection`——脚注先于链接，因为 `[^1]` 有定义后就是合法的引用链接。
- `MarkdownEditHistory` 用 `record` 记录（时钟由 `at_ms~` 传入，同类单字符编辑
  在 500 ms 内合并）、`undo` / `redo` 回放，并提供 `can_undo` / `can_redo` /
  `clear`。`selection_before~` / `selection_after~` 让撤销与重做返回带选区的
  `MarkdownEditOutcome`；`None` 回退到光标，源文本分歧时返回 `None`。

## 双链（可选开启）

- `MarkdownWikiLinkOptions::new(scheme)` 加 `with_wiki_links` 开启 `[[目标]]` 与
  `[[目标|别名]]`；默认关闭，包内不内置 scheme，由应用注入。
- 行内保留原始目标以支持无损往返，只在点击时解析。`MarkdownInline` 新增
  `wiki : Bool = false`，由它（而非 URL 前缀）驱动回写，目标是 `wiki:foo` 的
  普通链接不会被改写。

## 阅读视图与编辑器外壳

- `markdown_viewer` 新增 `palette~`（参与文档缓存键）、`compact_blank_gaps~`
  （折叠非活动间隔，命中测试与绘制同样生效）与 `wiki_links~`。
- 表格改用可见区间源头偏移加字素簇推进、逐格裁剪绘制，光标命中助手加
  `line_index~`。
- `moui_markdown` 新增 `markdown_editor_surface_menu_items`（`action` 沿用既有
  命令词，一个字符串对应一个 `Msg`）与格式气泡（动作表、字形、标签、矩形助手）；
  气泡放不下时翻到光标下方，只夹 y 不夹 x。

## 验证

- `0.7.3 → 0.8.0`：24b2f880、daa109e9、7d3e2862（#30 合并）及版本提交。
  7d3e2862 上的 PR 门禁：1418/1418（wasm）、51/51（wasm-gc）、2770/2770
  （native）；本地 `moui_richtext` 387/387、`moui_markdown` 48/48，静态校验、
  生成接口与文档预算通过。26 个模块均已发布 `0.8.0`（逐个 HTTP 200，manifest
  未撤回）。

## 升级说明

- 更新依赖即可，既有符号与线协议未变；`MarkdownInline` 新增
  `wiki : Bool = false`，其 `to_json` 多一个键。
- MoMark 删掉 `editor_target_sync.mbt`、撤销分组、右键菜单表与
  `view_format_bubble.mbt`，改用上述 API。MoSpace 删除 `vendor/moui_richtext`，
  改用 `palette~`、`wiki_links~ = Some(MarkdownWikiLinkOptions::new("mospace-wiki:"))` 与
  `compact_blank_gaps~ = true`；折叠间隔默认仍关闭。
