# Code Editor Example

- `examples/code_editor/app` is a native MoUI code editor prototype, not a WebView/Monaco wrapper.
- The editable surface is `moui_richtext.controlled_rich_text_editor`; syntax coloring is generated by `code_editor_document`.
- Gutter/editor scroll sync uses `visible_scroll_state=Some(model.editor_scroll)` on the rich text editor plus the same `ScrollState` in the gutter `scroll_view`.
- Keep language-service behavior app-owned through `CodeLanguageRegistry` / `CodeLanguageProvider`.
- Providers cover tokenizer, completion, diagnostics, hover, and definition callbacks.
- Native entrypoints are `macos_skia`, `windows_skia`, and `linux_skia`; there is intentionally no `web_wasm` entrypoint.
- Focused validation: `moon test examples/code_editor/app --target native` plus native checks for the three Skia entrypoints.
