# MoUI 0.7.3 — Same-window native dev reload

Patch release since `0.7.2`. All 26 public modules move to `0.7.3` together on
the existing `0.7.x` line (ADR 0065); no public package boundary, published API,
or wire contract changes. The release adds an opt-in macOS dev loop and turns
the recent CI gate fixes into the baseline.

## Native dev hot reload (macOS)

- `moui dev <app> --hot` keeps the window, renderer and platform services in a generated host; the app package is rebuilt as a `foreign_library` plugin and loaded at a new generation path. State and transient transports survive the swap, and a compiler error keeps the previous UI interactive.
- `moui_devhost` is a dev-only workspace module and is not published; generated sources stay under gitignored `moui_devhost/dev_hot/`. Core, renderer, backend and ABI edits still restart; IME/semantics are Phase 2.
- Warm counter reloads measured p50 ≈ 0.63 s. macOS keeps MoonBit dylibs mapped after `dlclose`, so the host re-execs after 32 successful swaps (`MOUI_HOT_RELOAD_LIMIT`, `0` disables).

## CI and docs

- Smoke and fallback gates consume the Skia prebuild contract; the deployed website asserts only the docs the catalog actually emits.
- ADR 0072, `docs/development.md` and `docs/tea-program-model.md` record the dev-loop contract and limits.

## Verification

- Range `0.7.2 → 0.7.3`: dff515c3, 677ef590, 6980b773, c7fbb6e9, e0ad6ae2,
  0ce990ce, 88af6749, plus the version commit. CI run RUN_ID is green on SHA.
- Local: protocol 4/4, `moui_cli` 229/229, counter 3/3, runtime 254/254, views
  42/42; static validators and the doc budget pass. Registry: all 26 modules
  return `Server status: 200 OK`.

## Upgrade notes

- Update dependencies; no public symbol or wire change. The `wzzc-dev/window`
  pin stays `0.5.4-0.2.13`.
- `--hot` is macOS-only and dev-only; the target app module must be listed in
  `moui_devhost/moon.mod` (counter is). Other platforms keep restart + state.

# MoUI 0.7.3 —— 同窗口原生开发重载

自 `0.7.2` 以来的补丁版本。26 个公开模块统一到 `0.7.3`，仍在 `0.7.x`
发布线（ADR 0065）；公开包边界、已发布 API 与线协议均未变。本版新增可选的
macOS 开发回路，并把近期的 CI 门禁修复纳入基线。

## 原生开发热重载（macOS）

- `moui dev <app> --hot` 由生成宿主保留窗口、渲染器与平台服务；应用包重建为
  `foreign_library` 插件，并从新的 generation 路径加载。状态与 transient
  传输在换插件后继续生效，编译错误时旧 UI 保持可交互。
- `moui_devhost` 仅为开发期 workspace 模块，不发布；生成源码位于 gitignore 的
  `moui_devhost/dev_hot/`。core、渲染器、backend 与 ABI 变更仍需重启；
  IME/语义属 Phase 2。
- counter 热重载 warm p50 ≈ 0.63 s。macOS 在 `dlclose` 后保留 MoonBit dylib
  映射，宿主在 32 次成功换插件后自重启（`MOUI_HOT_RELOAD_LIMIT`，`0` 关闭）。

## CI 与文档

- smoke 与 fallback 门禁消费 Skia prebuild 契约；网站部署只断言 catalog 实际产出的文档。
- ADR 0072、`docs/development.md` 与 `docs/tea-program-model.md` 记录开发回路契约与限制。

## 验证

- `0.7.2 → 0.7.3` 范围：dff515c3、677ef590、6980b773、c7fbb6e9、e0ad6ae2、
  0ce990ce、88af6749 及版本提交。CI run RUN_ID 在 SHA 上为绿。
- 本地：protocol 4/4、`moui_cli` 229/229、counter 3/3、runtime 254/254、
  views 42/42；静态校验与文档预算通过。注册表：26 个模块均返回
  `Server status: 200 OK`。

## 升级说明

- 更新依赖即可；公开符号与线协议未变。`wzzc-dev/window` 的 pin 仍是
  `0.5.4-0.2.13`。
- `--hot` 仅限 macOS 开发期；目标应用模块须列入 `moui_devhost/moon.mod`
  （counter 已列入）。其他平台继续使用重启 + 状态恢复。
