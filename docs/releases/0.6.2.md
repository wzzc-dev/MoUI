# MoUI 0.6.2 — Visual Baseline and Window Surface Polish

Patch release since `0.6.1`. All 25 public modules move to `0.6.2` together on
the existing `0.6.x` release line (ADR 0065; the line does not advance).

This release carries the visual-quality baseline (ADR 0071), the macOS native
window background and system-accent work from `wzzc-dev/window`
`0.5.4-0.2.10`/`0.5.4-0.2.11`, rich-text hot-path work, scoped animation damage,
the headless `moui screenshot` CLI, and the CI/build fixes that unblocked the
Windows real-Skia gates.

## Visual quality baseline (ADR 0071)

- **Desktop preset**: typography, radius, shadow, and layout scales, compact
  control metrics, neutral state layers, and tonal sidebar selection. Default
  widgets built without custom styling are expected to read as a shippable
  desktop surface.
- **Typography**: `FontSpec` gains line height, letter spacing, and OpenType
  feature controls; the values feed declaration keys so text reflows when line
  height is tracked instead of being measured once.
- **Icons**: an SVG path parser, a vendored Lucide set (103 icons) with a
  freshness generator, and an SF Symbols name bridge in `views/style`.
- **Surfaces**: conic and multi-stop gradients with Oklab interpolation,
  material/backdrop blur, scroll-edge fade, and capability declarations across
  Skia, Sun, Web, and WGPU.
- **Motion**: pressable transitions share one ≤150 ms timing model and snap to
  zero under reduced motion.
- **System accent**: the window host reports the macOS control accent
  (`window 0.5.4-0.2.10`); the resolver prefers an app seed, then the system
  accent on Desktop, then the preset fallback. Minimal ignores the system
  accent.
- **Dark-frame clear**: the runtime frame clear now follows the root-scoped
  theme background, so a dark root view no longer sits on a white page.
- **Gates and artifacts**: `--profile visual` covers the
  `{default, hover, pressed, focused, disabled} × {light, dark}` control matrix,
  per-control previews, and gallery screenshot freshness; README and website
  screenshots are regenerated from the gallery, and
  `node scripts/validate-visual-tokens.mjs` rejects bare colors and font sizes
  in `moui/views` paint paths.
- **Tree polish**: `TreeItem` gains optional `icon` / `icon_color`, ignored
  entries can render dimmed, the selected row uses the tonal fill, and rows are
  28 px to match denser desktop trees.
- **Rich-text palette**: `MarkdownRichTextPalette` carries the baked markdown
  colors (`light()` keeps the historical palette, `dark()` is the readable
  default). The session holds the palette and the projection cache keys on its
  digest, so a theme switch re-projects instead of serving light blocks.

## macOS window surface

- `wzzc-dev/window@0.5.4-0.2.11` adds a native window background setter and
  migrates the remaining `derive` declarations in the windowing package.
- `MacosHostAppOptions.window_background` creates the window hidden, applies
  the color, and shows it immediately (or on first present), removing the
  AppKit white flash before the app's own frame is drawn — the MoMark editor
  was the end-to-end case.

## Rich-text performance

- Per-block line heights and widths are cached by identity within a frame and
  reused by paint, selection rects, and caret lookup.
- Editing a table cell reparses only that table block when the pipe layout is
  unchanged, instead of falling back to the whole document.
- Same-line deletions (backspace) stay on the in-line fast path; region
  re-parses now happen only for newline or line-start edits.
- Retained paint-layer bounds stay in view coordinates, so headings scroll with
  their line-spacing block instead of leaving blank gaps.

## Runtime

- Animation-frame damage is collected from the deepest animating render nodes
  instead of marking the root dirty, so a scrolling editor no longer damages the
  whole window every frame. An empty animating set still falls back to the root.

## CLI

- `moui screenshot [project]` renders one offscreen frame and writes a PNG with
  no Node or Python dependency. Options: `--app`, `--out`, `--width`,
  `--height`, `--scale`, `--scheme`, `--renderer`, `--keep-temp`, and `--json`.
  The app package must expose `pub fn program()` and the project module must
  depend on the selected renderer.

## CI and build fixes

- Windows release/source archive extraction prefers the runner's `tar.exe`;
  `Expand-Archive` remains the fallback for hosts without bsdtar.
- The Skia acceptance, renderer, fallback, CI, and manual Windows jobs now
  pre-extract wgpu-native with `prepare-wgpu-native`. A root-level
  `moon build` of a `tools` package syncs every `moon.work` member — including
  the WGPU renderer modules — so the `wgpu_mbt` prebuild ran even in Skia-only
  jobs.
- The native configure scripts keep backdrop blur in the native/fallback target
  maps and register `native.backdrop-blur` in `capabilities.json`, so real-Skia
  builds no longer compile both the native and unavailable blur sources.
- Native configure scripts resolve from the native package directory instead of
  assuming the MoUI repository root.
- `moui/views/data` splits the tree row renderer into `data_tree_row.mbt` and
  keeps `tree_item` next to `tree_view`, bringing both files back under the
  maintenance line budgets.
- The TUI projection test now asserts that the externally compacted tree tail is
  visible; clipping coverage remains on the list tail and the offscreen node
  count.

## Verification

- The 0.6.1 → 0.6.2 range includes PR #22 (visual-quality baseline) and PR #23
  (macOS window background).
- Local gates: `moui/views` 42/42, `moui_tests/tui_spike` 8/8, `moon fmt
  --check`, and the static validator set (maintenance baseline, API surface,
  release closures, portfolio governance, guidance, renderer capability, doc
  references) pass.
- 0.6.2 CI: the `MoUI CI` workspace baseline and PR profile gate, the Windows
  static/dynamic real-Skia acceptance jobs, and the external consumer matrix
  passed on the release commit.
- Registry publication and external-consumer verification are the remaining
  release steps for this line.

## Upgrade notes

- Update dependencies; no public symbol was removed. `wzzc-dev/window` moves
  from `0.5.4-0.2.9` to `0.5.4-0.2.11` (system accent, native window background,
  windowing derive migration). Update the window pin together with MoUI.
- The Desktop preset is the new default visual language (ADR 0071). Apps that
  pinned explicit colors, radii, or control sizes keep them, but default-themed
  surfaces will look denser and less flat; `Theme.layout_scale` is the intended
  knob for per-app density.
- `TreeItem` gains optional `icon` / `icon_color` fields; existing label-only
  trees continue to compile because both default to `None`.
- `moui screenshot` requires the target app package to expose `program()` and
  the project module to depend on the selected renderer (`skia` or `sun`).

# MoUI 0.6.2 — 视觉基线与窗口表面打磨

自 `0.6.1` 以来的补丁版本。25 个公开模块统一到 `0.6.2`，仍然留在 `0.6.x`
发布线（ADR 0065，本版不推进线号）。

本版包含视觉质量基线（ADR 0071）、来自 `wzzc-dev/window`
`0.5.4-0.2.10`/`0.5.4-0.2.11` 的 macOS 原生窗口背景与系统 accent、富文本
热路径优化、动画帧损伤收敛、无头 `moui screenshot` CLI，以及打通 Windows
真实 Skia 门禁的 CI/构建修复。

## 视觉质量基线（ADR 0071）

- **Desktop preset**：排版、圆角、阴影、布局比例、紧凑控件度量、中性状态层
  与 sidebar 的 tonal 选中态。不写自定义样式、只用默认主题搭出的界面，按
  可发布桌面产品的标准交付。
- **排版**：`FontSpec` 支持行高、字距与 OpenType feature；这些值进入
  declaration key，行高变化会真正触发文本重排，而不是只测量一次。
- **图标**：SVG path 解析器、随仓库维护的 Lucide 图标集（103 个）与
  freshness 生成器，以及 `views/style` 里的 SF Symbols 名称桥。
- **表面**：conic/多 stop 渐变（Oklab 插值）、material/backdrop blur、
  scroll-edge fade，并在 Skia、Sun、Web、WGPU 中声明能力。
- **动效**：所有可交互控件共享 ≤150 ms 的按压过渡；reduced motion 下直接
  吸附到终态。
- **系统 accent**：window host 上报 macOS 的 control accent
  （`window 0.5.4-0.2.10`）；解析顺序为 app seed → Desktop 系统 accent →
  preset fallback。Minimal 忽略系统 accent。
- **暗色帧清屏**：runtime 的清屏颜色改为读取根视图作用域的主题背景，暗色根
  视图不再出现白底。
- **门禁与产物**：`--profile visual` 覆盖
  `{default, hover, pressed, focused, disabled} × {light, dark}` 控件矩阵、
  单控件预览与 gallery 截图 freshness；README 与官网截图由 gallery 重新生成；
  `node scripts/validate-visual-tokens.mjs` 禁止 `moui/views` 绘制路径出现
  裸颜色与裸字号。
- **树控件打磨**：`TreeItem` 新增可选 `icon` / `icon_color`；被忽略的条目
  可以按 muted 色降级显示；选中行改用 tonal 填充；行高调整为 28 px，贴近
  更紧凑的桌面树。
- **富文本调色板**：`MarkdownRichTextPalette` 承载 markdown 烘焙颜色
  （`light()` 保持历史配色，`dark()` 是可读的暗色默认值）。session 持有
  palette，投影缓存以 palette digest 为 key，切换主题会重新投影而不是继续
  使用浅色块。

## macOS 窗口表面

- `wzzc-dev/window@0.5.4-0.2.11` 增加原生窗口背景色设置，并把 windowing 包里
  剩余的 `derive` 声明迁移到属性。
- `MacosHostAppOptions.window_background` 先以隐藏状态创建窗口、应用背景色，
  再立即显示（或等首帧显示），消除 AppKit 在 MoUI 首帧之前的白闪 ——
  MoMark 编辑器是端到端验证场景。

## 富文本性能

- 同一帧内按 identity 缓存每个 block 的行高与行宽，paint、选择框与 caret
  查找共用，不再重复切分测量。
- 表格单元格编辑在 pipe 布局不变时只重解析该表格 block，不再回退到整篇
  文档。
- 同一行内的删除（退格）继续走 in-line 快路径；region 重解析只保留给换行
  或行首编辑。
- retained paint-layer 的边界保持在视图坐标中，标题滚动时跟随自己的行距块，
  不再留下空白 gap。

## 运行时

- 动画帧的损伤区域改为收集最深层正在动画的 render node，而不是把根节点标
  脏；滚动中的编辑器不再每帧损伤整个窗口。动画集合为空时仍回退到根节点。

## CLI

- `moui screenshot [project]` 离屏渲染一帧并输出 PNG，不依赖 Node 或 Python。
  选项：`--app`、`--out`、`--width`、`--height`、`--scale`、`--scheme`、
  `--renderer`、`--keep-temp`、`--json`。目标 app 包必须暴露
  `pub fn program()`，项目模块必须依赖所选渲染器。

## CI 与构建修复

- Windows 发布/源码压缩包优先使用 runner 自带的 `tar.exe` 解压；
  没有 bsdtar 的宿主仍回退到 `Expand-Archive`。
- Skia acceptance、renderer、fallback、CI 与 manual Windows job 统一用
  `prepare-wgpu-native` 预解压 wgpu-native。根目录构建 `tools` 包会同步整个
  `moon.work`（包含 WGPU 渲染器模块），因此纯 Skia job 也会触发 `wgpu_mbt`
  的 prebuild。
- native configure 脚本把 backdrop blur 保留在 native/fallback target map，
  并在 `capabilities.json` 注册 `native.backdrop-blur`，真实 Skia 构建不再
  同时编译 native 与 unavailable 两个 blur 源。
- native configure 脚本改为从 native 包所在目录解析，不再假设 MoUI 仓库根。
- `moui/views/data` 把树行渲染拆到 `data_tree_row.mbt`，`tree_item` 留在
  `tree_view` 旁边，两个文件都回到维护行数预算内。
- TUI projection 测试改为断言紧凑排版后的树尾完整可见；裁切覆盖仍由左栏
  列表与 offscreen 计数承担。

## 验证

- 0.6.1 → 0.6.2 范围包含 PR #22（视觉质量基线）与 PR #23（macOS 窗口背景）。
- 本地门禁：`moui/views` 42/42、`moui_tests/tui_spike` 8/8、
  `moon fmt --check`，以及静态校验套件（maintenance baseline、API surface、
  release closures、portfolio governance、guidance、renderer capability、
  doc references）全部通过。
- 0.6.2 的 CI：`MoUI CI` 的 workspace baseline 与 PR profile gate、Windows
  static/dynamic 真实 Skia acceptance、外部消费者矩阵在发布提交上全部通过。
- 注册表发布与外部消费者验证是本发布线剩余步骤。

## 升级说明

- 更新依赖即可，没有公开符号被删除。`wzzc-dev/window` 从 `0.5.4-0.2.9`
  前进到 `0.5.4-0.2.11`（系统 accent、原生窗口背景、windowing derive 迁移），
  请与 MoUI 一起更新 pin。
- Desktop preset 成为新的默认视觉语言（ADR 0071）。显式指定颜色、圆角或
  控件尺寸的 app 保持原样，但默认主题的界面会更紧凑、更少扁平感；
  `Theme.layout_scale` 是预期的密度调节旋钮。
- `TreeItem` 新增可选 `icon` / `icon_color` 字段；两者默认 `None`，纯标签树
  继续编译。
- `moui screenshot` 要求目标 app 包暴露 `program()`，且项目模块依赖所选
  渲染器（`skia` 或 `sun`）。
