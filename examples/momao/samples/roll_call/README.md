# 教案：班级点名册 / Lesson: Class Roll Call

- 建议学段：小学 3–6 年级 / 职校通识课
- 时长：1 课时（40 分钟）
- 模板：顶栏「班级点名册」（或对 AI 说「帮我做一个随机点名」）

## 教学目标

1. 知道「清单（列表框）+ 随机数」可以做一个有用的工具。
2. 读懂三行程序：数一下有几个人 → 抽一个序号 → 显示那个人。
3. 体验三视图同源：设计视图挪控件、积木视图看步骤、代码视图读中文。

## 课堂步骤

1. **跑起来**（5 分钟）：打开模板，点「随机点名」几次，让学生发现
   每次结果不同、且不会超出名单范围。
2. **读程序**（10 分钟）：切到代码视图，逐行读：
   `变量 人数 = 取行数(名单)` / `变量 序号 = 随机数(人数)` /
   `设置文本(结果, 取行(名单, 序号))`。提问：为什么是 `随机数(人数)`
   而不是 `随机数(10)`？
3. **改一改**（10 分钟）：在设计视图把「名单」加长（属性面板每行一个
   名字），再运行，验证点名范围跟着变。
4. **挑战**（10 分钟）：让程序点到人后说一句「请回答问题」。提示：
   `信息框(...)`，把谁被点到传进去。
5. **展示与讨论**（5 分钟）：切到英文界面，同一份程序变成
   `let`/`if` 的样子——程序和语言的关系是什么？

## 评价

- 能解释「为什么序号不会超过人数」。
- 能独立把名单改成自己班级的名单并跑通。

## 拓展（课后）

- 加入「不重复点名」：记住点过的人（提示：用变量累加 + 判断）。
- 把点到的同学换成随机抽取一道题目（列表框里放题目）。
