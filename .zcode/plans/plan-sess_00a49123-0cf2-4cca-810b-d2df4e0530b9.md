# 全量 native Skia 默认 GPU

## 目标

把 **全部 native Skia 后端**（macOS / Windows / Linux / iOS / Android / HarmonyOS）的 **`auto` 默认改为 GPU**。  
Web 已是 WebGPU，只同步文档；native WGPU 诊断路径不动。

策略按你的选择：**不等 matching-device 证据，直接切产品默认**；保留：

- 显式 `--renderer skia-raster` / `MOUI_SKIA_RENDERER=skia-raster`
- GPU 不可用 / attach 失败 / context-loss 后的 **sticky raster 回退**
- `skia-gpu` 显式请求语义不变

这会 **覆盖 ADR 0006 / invariants R2–R3 的“先证据再 promote”策略**，文档必须改成新策略并标明风险。

## 现状（为何只改 flag 不够）

| 层 | 现状 | 全量默认 GPU 需要 |
|---|---|---|
| Runtime 选择 | 仅 `Macos.gpu_promoted()=true`；`auto` 需 `gpu_available && gpu_promoted` | 全平台 `true` |
| Desktop 构建 | macOS Metal 在 darwin 宿主默认开；Win/Linux GPU 需 env opt-in | 按目标平台默认开 GPU 后端 |
| Mobile 打包 | `prepare-native-build.mjs` 的 `auto` **硬编码** `skia-raster` + `gpuPromoted:false` | `auto` → `skia-gpu` 并注入 GPU 链接 |
| 部分 macOS 示例/smoke | `MOUI_MACOS_SKIA_SURFACE_ROUTE` 未设时强制 raster | 默认跟随 provider/`MOUI_SKIA_RENDERER` |
| Web | 已是 WebGPU | 文档对齐即可 |

核心选择逻辑：`moui/render/native_gpu_selection.mbt` 的 `select_native_renderer`。

## 实现步骤

### 1. Runtime 默认门禁

**文件：** `moui/render/native_gpu_selection.mbt`

- `NativeGpuPlatform::gpu_promoted`：全部平台返回 `true`（Macos 已 true，Windows/Linux/Android/Ios/HarmonyOs 一并 true）
- 注释改为：默认 GPU；raster 仅显式请求或不可用/恢复失败时

**测试：** `moui/render/native_gpu_selection_test.mbt`

- 原 “only macos promoted” → 断言 **全部 true**
- “auto remains raster before promotion” → 改为 **注入 `gpu_promoted=false` 的语义测试**（保留规则覆盖），或改为 “auto selects gpu when available and promoted”
- 补充/调整：各平台 `auto` + `gpu_available=true` → 对应 GPU route（Metal/D3D/Vulkan/EGL）

**已有注入 bool 的测试保持：**  
`moui/backend/host/host_rendering_test.mbt` 用 kwargs，无需改语义。

**运行时测试：** `moui/backend/host/mobile_renderer_runtime_test.mbt`

- Android/iOS `auto` 在 `gpu_available` 时应变 GPU
- status JSON `"gpuPromoted":true`

### 2. Mobile 构建打包默认 GPU

**文件：** `moui/scripts/mobile/prepare-native-build.mjs` → `selectRenderer`

当前：

```js
// auto / 非 skia-gpu → skia-raster, gpuPromoted: false
```

改为：

| requested | fallbackSkia | selected | gpuPromoted |
|---|---|---|---|
| `skia-raster` | any | `skia-raster` | false |
| `skia-gpu` | false | `skia-gpu` | true |
| `skia-gpu` | true | `skia-raster` + reason | false |
| `auto` | false | **`skia-gpu`** | **true** |
| `auto` | true | `skia-raster` + reason | false |

确保现有 `skia-gpu` 分支注入的 GPU env / static link / `MOUI_SKIA_ENABLE_GPU_*` 在 **`auto` 选中 GPU 时同样生效**。

CLI 默认仍可是 `--renderer auto`（语义变为默认 GPU）。

相关：`build-android-apk.sh` / `build-ios-app.sh` / `build-harmonyos-hap.sh` / gradle 文案若写 “auto = raster until promotion”，一并改。

### 3. `moui_skia` 构建默认打开各平台 GPU

**文件：** `moui_skia/build.js`

对齐 macOS Metal 已做的 “promotion 后 default-on”：

- **Metal（macOS / iOS / iosSim）：** `skiaMetalGpuEnabled` 按 **目标平台** 默认 true（显式 env 可关），避免仅 `process.platform === "darwin"` 宿主门控带来的歧义
- **Windows D3D12 / Linux Vulkan / Android Vulkan+EGL / HarmonyOS EGL：** `skiaGpuEnabled` 从 “仅 env opt-in” 改为 **目标平台默认 true**，`MOUI_SKIA_ENABLE_GPU_*=0` 可关
- 缺 `libskia_ganesh_ext` 时：行为与现有一致（报错或明确不启用），避免静默假 GPU

`moui/build.js` 仅代理 prebuild，一般不用改选择逻辑。

### 4. Provider / 示例入口对齐默认

**Desktop providers**（已接 `select_native_renderer` + `gpu_promoted`）：  
`macos|windows|linux/skia/*_skia_provider.mbt` — 逻辑可不动，flag 翻转后 `auto` 即 GPU。

**Mobile providers：**  
`Ios/Android/HarmonyOsSkiaAppOptions::new` 默认仍是 `RasterSurfaceRoute`；示例已通过 `mobile_renderer_selection` 注入 route。建议：

- 示例路径确认全部传 `selection.surface_route`（counter / component_gallery / harmonyos_demo 已有）
- 可选加固：默认 `surface_route` 改为 “未指定时按 platform selection”，改动面更大，**非必须**（优先保证示例与文档）

**macOS 硬编码 raster 的入口** — 改为跟随默认 GPU：

- `examples/showcase|markdown_editor|mo_workbench/macos_skia/main.mbt`
- 优先：删除强制 raster，改用 provider 默认 / `MOUI_SKIA_RENDERER`
- 或：`MOUI_MACOS_SKIA_SURFACE_ROUTE` 未设时用 `macos_surface_route_from_environment` 等价逻辑，而不是默认 `RasterSurfaceRoute`

**Smoke 入口**（`moui_tester/macos_skia_*`）：

- 可保留 env 强制 metal-gpu（证据脚本依赖）
- 未设 env 时改为跟随 `auto`（GPU），避免 “promoted 后 tester 仍默认 raster” 的不一致  
  若 smoke 脚本已显式 export `metal-gpu`，可只改注释

## 验证

```sh
# 选择逻辑
MOUI_SKIA_DISABLE_PREBUILD_SKIA=1 moon test moui/render --target native
MOUI_SKIA_DISABLE_PREBUILD_SKIA=1 moon test moui/backend/host --target native

# 若环境允许
moon test moui/backend/macos/skia --target native
# windows/linux 按宿主

# mobile prepare 单测/脚本（若有）
node -e "/* 或现有 prepare-native-build 测试入口 */"

# 策略文档一致性（若脚本覆盖相关句）
node scripts/validate-guidance-consistency.mjs
```

手动/半自动：

- macOS：`MOUI_SKIA_RENDERER=auto` 日志应含 `surface_route=metal-gpu`（Metal 可用时）
- 显式：`MOUI_SKIA_RENDERER=skia-raster` 仍 raster
- 移动：`scripts/build-mobile-*-app.sh --renderer auto` 的 `mobile-build.json` 应为 `selected: skia-gpu`, `gpuPromoted: true`

## 风险（写进提交说明）

- Windows / Linux / 真机移动端 **缺少 7-gate 证据**；默认 GPU 可能 attach 失败后频繁回退 raster，或在部分 OEM/合成器上不稳定
- 构建默认开 Ganesh 可能增加链接体积与 prebuild 失败面（缺 ganesh_ext 时需清晰错误）
- 与历史 ADR “先证据再 promote” 决裂——文档必须同步，避免后续 agent 按旧 R3 回滚
